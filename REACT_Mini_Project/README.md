# 🚀 FolioGen — Portfolio Generator

FolioGen is a production-grade, SaaS-style portfolio generator that I worked on as part of a team project. It enables professionals to create stunning, fully customizable portfolio websites in minutes — without writing a single line of code. The app is built using a modern frontend stack including React 19, Vite, and a custom CSS design system.

***

## ✨ Key Features

- 🏗️ Multi-Step Builder: I developed the core 6-step guided wizard (Personal → Skills → Projects → Social → Appearance → Preview) to ensure a smooth and intuitive user experience.

- 👁️ Real-time Live Preview: The portfolio updates instantly alongside user input, allowing users to visualize changes in real time.

- 🌗 Dark & Light Mode: Seamless theme switching across both the builder interface and generated portfolio.

- 📄 Export & Print: Users can export their portfolio as a standalone HTML file or print it directly to PDF.

- 🎨 8 Curated Color Palettes: Predefined themes like Indigo Nights, Emerald Forest, and Sunset Blush for quick customization.

- 📐 4 Layout Templates: Includes Modern, Split, Minimal, and Creative layouts.

- 🖼️ Project Showcase: I implemented components that allow users to upload images, tag technologies, and link projects.

- 🔗 Social Integration: Easily connect platforms like GitHub, LinkedIn, Twitter/X, and more.

- 💾 Persistent Storage: All data is saved using LocalStorage, ensuring progress is never lost.

- 🌐 Premium Landing Page: A polished SaaS-style landing page with animations and structured sections.

***

## 🛠️ Tech Stack

- Core: React 19 + Vite 8  
- Routing: React Router DOM v7  
- Styling: Custom CSS Design System with CSS Variables  
- State Management: Context API + useReducer with LocalStorage  
- Icons: Lucide React  
- Typography: Outfit, Inter, JetBrains Mono  
- Export: Native HTML generation & Browser Print API

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)  
- npm or yarn  

### Installation

1. Clone the repository:
   git clone https://github.com/ramjeemishra/React_Mini_Project.git  
   cd React_Mini_Project  

2. Install dependencies:
   npm install  

3. Start development server:
   npm run dev  

4. Open in browser:
   http://localhost:5173

## 📝 Usage Notes

- Images are stored as Base64 in LocalStorage; large files may affect performance  
- Clearing browser storage will reset all data  
- Exported HTML files are fully standalone  
- Builder is optimized for desktop; generated portfolios are fully responsive
